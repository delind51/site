# VLADIMIR IALAMA

Персональный сайт / Personal Index. Этап 3 — первый экран, четыре основных раздела, шаблоны разделов и первая страница материала.

## Просмотр

Открыть `index.html` в браузере напрямую или через VS Code Live Server.
Уже имеющийся локальный Node-сервер запускается командой `npm start`,
после чего сайт доступен по адресу http://localhost:3000/index.html.
Зависимости устанавливать не требуется. Остановка сервера — `Ctrl+C`.

Быстрая проверка локального сервера:

```bash
npm run check
```

## Файлы

- `index.html` — основной русский вариант.
- `en/index.html` — английский вариант.
- `PROJECT_STRUCTURE.md` — карта маршрутов и правила добавления новых материалов.
- `styles.css` — общие стили, палитра и адаптивная композиция.
- `script.js` — минимальный JavaScript и единый список материалов для автоматической навигации prev / next.
- `assets/social-card.png` — активная preview-картинка для шаринга.
- `assets/social-card-alt-clean.png` — запасной более чистый вариант preview-карточки.
- `server.js`, `package.json` — необязательный локальный сервер.
- `.nojekyll` — служебный файл для GitHub Pages, чтобы сайт отдавался как обычная статика.

Повторяющиеся `index.html` нужны специально: так статический сайт получает чистые URL
вида `/places/`, `/places/cologne/`, `/projects/experiments/`.
Короткие `README.md` внутри `places/`, `frequency/`, `objects/`, `projects/`
объясняют, что лежит в каждой группе.

Сайт работает без JavaScript. Пути к ресурсам относительные.
Onest загружается из Google Fonts, поэтому для него нужен интернет;
запасной шрифт — Arial. Локальное размещение шрифта можно рассмотреть
на этапе финальной подготовки.

Порядок материалов внутри разделов контролируется в `entryRegistry` в `script.js`.
Нижняя навигация «предыдущий / следующий» на страницах материалов строится из этого списка.
HTML-блоки `entry-pager` оставлены как fallback, если JavaScript выключен.

## Публикация

Проект можно публиковать на GitHub Pages из корня репозитория. Отдельная сборка не нужна:
все страницы, стили и скрипты уже лежат как статические файлы.

## Добавление материала без ручного HTML

1. Открыть `/admin/`.
2. Заполнить материал и скачать `Draft JSON`.
3. Положить JSON в `content/<section>/<slug>.ru.json`, например `content/places/my-trip.ru.json`.
4. Положить фотографии в папку из поля `paths.uploads`, например:
   `content/uploads/places/my-trip/`.
5. Запустить генерацию:

```bash
npm run publish-entry -- content/places/my-trip.ru.json
```

Скрипт создаст страницу материала и добавит её в список раздела.

Для сайта лучше использовать `.jpg`, `.jpeg`, `.png`, `.webp`. RAW/DNG стоит заранее
экспортировать в JPEG/WebP, потому что браузеры обычно не показывают DNG как обычные картинки.

## Утверждённое направление

Onest 400/500/600, композиция B с вертикальным портретом 3:4.
Русский основной, английский по переключателю RU / EN.
Имя остаётся латиницей. Фон #F1F2F4, текст #111214, вторичный текст
#656A71, линии #D4D8DE. Акцент #2353F5 остаётся предварительным
до предоставления референса Bruno.

На телефоне имя и фотография расположены последовательно.
Портрет и изображения разделов пока заменены нейтральными плейсхолдерами.
Главный индекс состоит из четырёх направлений: Места / Частота / Объекты / Проекты.
Все четыре раздела главного индекса уже кликабельные.
«Обо мне» / About ведёт к нижнему блоку на главной.
Социальные ссылки в About ведут на GitHub, Telegram, Instagram и email.
